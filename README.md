## Query Parameters

Every parameter below is parsed by `streakParamsSchema` and reaches the SVG generator. All are optional except `user`. Invalid values fall back to the listed default rather than erroring.

### Core

| Parameter | Controls | Values |
| --- | --- | --- |
| `user` | GitHub handle to render. Accepts a comma-separated list to aggregate. | GitHub username (max 39 chars) |
| `theme` | Colour preset. | Any theme key from the table above, plus `auto`, `random` — default `dark` |
| `view` | Which visualisation renders. | `default`, `monthly`, `heatmap`, `pulse`, `skyline`, `languages`, `radar`, `doughnut`, `pie`, `activity_graph`, `commit_clock`, `weekday`, `punchcard`, `spotlight` — default `default` |
| `format` | Response type. | `svg`, `json`, `png` — default `svg` |
| `repo` | Target repository for `view=spotlight`. | Repository name |
| `org` | Scope contributions to one organisation. | Organisation login |
| `versus` | Renders a head-to-head card against a second user. | GitHub username |
| `mode` | What the towers measure. | `commits`, `loc` — default `commits` |

### Colour

| Parameter | Controls | Values |
| --- | --- | --- |
| `bg` | Background colour, overriding the theme. | Hex without `#` (3/4/6/8 digits) |
| `text` | Label and stat text colour. | Hex without `#` |
| `accent` | Tower and highlight colour. Accepts up to 4 comma-separated values for a multi-stop accent. | Hex without `#` |
| `border` | Card border stroke. | Hex without `#` |
| `bgType` | Background fill style. | `solid`, `linear`, `radial` — default `solid` |
| `bgStart` / `bgEnd` | Gradient stops when `bgType` is `linear` or `radial`. | Hex without `#` |
| `bgAngle` | Linear gradient angle. | `0`–`360` — default `90` |
| `gradient` | Enables an accent gradient on the towers. | `true`, `false` — default `false` |
| `gradient_stops` | Custom accent gradient stops. | Comma-separated hex values |
| `gradient_dir` | Accent gradient direction. | `vertical`, `horizontal`, `diagonal` — default `vertical` |
| `opacity` | Tower opacity. | `0.1`–`1.0` — default `1.0` |

### Layout and type

| Parameter | Controls | Values |
| --- | --- | --- |
| `size` | Overall badge scale. | `small`, `medium`, `large` — default `medium` |
| `width` | Explicit width override. | `100`–`1200` |
| `height` | Explicit height override. | `80`–`800` |
| `radius` | Corner radius. | `0`–`50` — default `8` |
| `font` | Typeface. Bundled faces render everywhere; other names load from Google Fonts. | `jetbrains`, `fira`, `roboto`, `syncopate`, `spacegrotesk`, or a font name |
| `scale` | How commit counts map to tower height. | `linear`, `log`, `sqrt` — default `linear` |
| `theta` | Isometric rotation angle. | `0`–`360` |
| `phi` | Isometric tilt angle. | `0`–`90` |

### Content and visibility

| Parameter | Controls | Values |
| --- | --- | --- |
| `custom_title` | Replaces the generated title. | Text (max 200 chars) |
| `custom_subtitle` | Replaces the generated subtitle. | Text (max 200 chars) |
| `label` | Overrides or hides the stat labels. | Text, or `true` / `false` |
| `labels` | Shows the extra label row. | `true`, `false` |
| `labelColor` | Colour for that label row. | Hex without `#` |
| `hide_title` | Hides the title. | `true`, `false` |
| `hide_background` | Renders the card transparent. | `true`, `false` |
| `hide_stats` | Hides the stat row. | `true`, `false` |
| `hide_weekend` | Excludes weekends from the towers. | `true`, `false` — default `false` |
| `badges` | Draws achievement badges. | `true`, `false` — default `false` |
| `delta_format` | How month-over-month change is shown. | `percent`, `absolute`, `both` — default `percent` |
| `lang` | Translates the three stat labels inside the SVG. | `en`, `zh`, `es`, `hi`, `pt`, `ko`, `ja`, `fr`, `ta`, `de` — default `en` |

### Motion and effects

| Parameter | Controls | Values |
| --- | --- | --- |
| `speed` | Animation duration. | `2s`–`20s` — default `8s` |
| `entrance` | Entrance animation style. | `rise`, `fade`, `slide`, `wave`, `bounce`, `none` — default `rise` |
| `glow` | Accent glow filter. | `true`, `false` — default `true` |
| `shading` | Adds face shading to the towers. | `true`, `false` — default `false` |
| `disable_particles` | Turns off ambient particles. | `true`, `1` |

### Data window

| Parameter | Controls | Values |
| --- | --- | --- |
| `year` | Calendar year to render. | 4-digit year, `2008`–current |
| `from` / `to` | Explicit date range. | ISO 8601 dates |
| `start_date` / `end_date` | Alternate range aliases. | ISO 8601 dates |
| `days` | Trailing window length. | `1`–`366` |
| `grace` | Missed days tolerated before a streak breaks. | `0`–`7` — default `1` |
| `tz` | Timezone the streak rolls over in. | IANA timezone — default `UTC` |

### Delivery

| Parameter | Controls | Values |
| --- | --- | --- |
| `refresh` | Forces a fresh upstream fetch, subject to rate limiting. | `true`, `false` |
| `bypassCache` | Skips the server cache for this request. | `true`, `false` |
| `minify` | Optimises the SVG output. | `true`, `false` — default `true` |

## 🚀 Features

### -> Generator

Builds a complete profile README around your badge — presets, tech stack, contribution visualisations, repository spotlight and socials — with a live preview and a copyable Markdown output.

Reads your public profile, repositories and top languages from the GitHub API, assembles the Markdown client-side as you edit, and renders the badge preview from the same `/api/streak` endpoint the final README embeds, so the preview is the real artifact rather than a mock.

### -> Compare

Puts two GitHub accounts head to head on contributions, streaks, languages and repository reach, with a winner banner and a shareable `?user1=&user2=` URL.

Fetches both profiles in parallel, scores them across weighted axes, and derives a radar and activity heatmap from the contribution calendars. Global counters for developers compared, repos analysed, languages tracked and comparisons today persist in MongoDB, keyed by the IST calendar date so the daily figure rolls over at 00:00 IST.

### -> Burnout Radar

Reads a repository's commit rhythm for signs of unsustainable pace and key-person risk, reporting a sustainability score alongside bus factor, contributor concentration and night/weekend share.

Walks the repository's commit history, buckets commits by weekday and hour to find after-hours and weekend load, computes contributor concentration for the bus factor, and pairs the heuristic findings with generated recommendations. A bot filter drops automation accounts before scoring.

### -> Customization Studio

Tunes every badge parameter against a live preview — 33 theme presets, custom colour overrides, layout, typography, visibility and language — then hands back the embed snippet in Markdown, HTML, React TSX or a GitHub Action.

Every control maps to a query parameter on `/api/streak`, so the studio's state, the preview and the exported snippet are all built from one encoder. The preview fetches the real badge rather than reproducing it, which is what keeps it byte-identical to what a README will show.
